# Практическая работа № 3
## Свёрточные нейронные сети (CNN). Решение задач биометрии

### 1. Цель работы

Изучение принципов работы свёрточных нейронных сетей (CNN), освоение методов предварительной обработки изображений, построение и обучение CNN для решения задачи классификации изображений.

### 2. Используемые технологии

- Python 3.13
- TensorFlow 2.21.0
- Keras
- MNIST Dataset
- VS Code

### 3. Описание набора данных

В работе использован набор данных MNIST, содержащий изображения рукописных цифр от 0 до 9.

Состав набора:
- Обучающая выборка — 60 000 изображений.
- Тестовая выборка — 10 000 изображений.
- Размер изображения — 28 × 28 пикселей.
- Количество классов — 10.

### 4. Предварительная обработка данных

Выполнены следующие операции:

1. Загрузка набора данных MNIST.
2. Изменение размерности изображений с добавлением канала цветности.
3. Преобразование значений пикселей в диапазон от 0 до 1 путём нормализации.
4. Преобразование меток классов в формат One-Hot Encoding.

### 5. Архитектура нейронной сети

Реализована последовательная модель CNN со следующими слоями:

1. Conv2D — 32 фильтра размером 3 × 3, функция активации ReLU.
2. MaxPooling2D — уменьшение размерности признаковых карт.
3. Conv2D — 64 фильтра размером 3 × 3, функция активации ReLU.
4. MaxPooling2D — повторное уменьшение размерности.
5. Flatten — преобразование многомерных признаков в одномерный вектор.
6. Dense — полносвязный слой из 128 нейронов с функцией ReLU.
7. Dense — выходной слой из 10 нейронов с функцией Softmax.

Количество обучаемых параметров — 225 034.

### 6. Обучение модели

Параметры обучения:

- Оптимизатор — Adam.
- Функция потерь — Categorical Crossentropy.
- Метрика качества — Accuracy.
- Количество эпох — 10.
- Размер пакета — 64 изображения.

### 7. Результаты

По результатам тестирования сохранённой модели получены следующие показатели:

- Точность классификации — 99,14%.
- Значение функции потерь — 0,0365.
- Проверка первых пяти тестовых изображений показала правильное распознавание всех пяти примеров.

Обученная модель сохранена в файле `cnn_mnist_model.keras`.

### 8. Структура проекта

- `main.py` — загрузка данных, предобработка, создание и обучение CNN, оценка результатов и сохранение модели.
- `predict.py` — загрузка сохранённой модели и выполнение предсказаний без повторного обучения.
- `cnn_mnist_model.keras` — сохранённая обученная модель.
- `requirements.txt` — список зависимостей проекта.

### 9. Вывод

В ходе практической работы была реализована и обучена свёрточная нейронная сеть для классификации изображений набора MNIST. Были освоены основные этапы подготовки изображений, построения архитектуры CNN, обучения модели и оценки её качества.

Полученная точность классификации составила 99,14%, что демонстрирует эффективность реализованной архитектуры для решения рассматриваемой задачи.

Следует отметить, что MNIST содержит изображения рукописных цифр и используется в данной работе как учебный пример применения CNN. Полученная модель не выполняет непосредственное распознавание лиц или отпечатков пальцев.
