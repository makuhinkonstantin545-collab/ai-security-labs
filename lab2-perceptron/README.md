# Лабораторная работа № 2. Однослойный и многослойный персептрон

## Цель работы

Изучить построение и обучение однослойного и многослойного персептронов для решения задачи бинарной классификации сетевого трафика.

## Используемые технологии

- Python 3
- NumPy
- Pandas
- Scikit-learn
- TensorFlow / Keras

## Содержание работы

1. Генерация искусственных данных двух классов: нормального и вредоносного трафика.
2. Разделение данных на обучающую и тестовую выборки.
3. Масштабирование признаков с помощью `StandardScaler`.
4. Создание и обучение однослойного персептрона.
5. Создание и обучение многослойного персептрона (MLP).
6. Оценка качества классификации с помощью Accuracy, Precision, Recall и F1-score.
7. Сравнение результатов двух моделей.

## Архитектура моделей

**Однослойный персептрон:** пять входных признаков и один выходной нейрон с функцией активации sigmoid.

**Многослойный персептрон:** скрытые слои из 32 и 16 нейронов с функцией активации ReLU, слой Dropout и выходной нейрон с функцией активации sigmoid.

## Результаты эксперимента

| Модель | Точность на тестовой выборке |
|---|---:|
| Однослойный персептрон | 92,67% |
| Многослойный персептрон | 94,00% |

## Вывод

В ходе работы были реализованы и сравнены две нейросетевые модели для бинарной классификации. На искусственно сгенерированных данных многослойный персептрон показал точность 94%, а однослойный — 92,67%.

Эксперимент демонстрирует принципы применения нейронных сетей для классификации, но не является проверкой обнаружения атак на реальном сетевом трафике.
