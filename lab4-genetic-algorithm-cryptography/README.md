# Практическая работа №4. Генетические алгоритмы в криптографии

## Цель работы

Изучить принципы генетических алгоритмов и применить их для криптоанализа простого шифра Цезаря. Для оценки качества расшифровки используется частотный анализ букв английского языка.

## Задачи работы

1. Реализовать шифрование и расшифровку шифром Цезаря.
2. Разработать функцию оценки приспособленности (Fitness Function).
3. Создать начальную популяцию случайных ключей.
4. Реализовать отбор лучших особей.
5. Реализовать генетические операторы: скрещивание и мутацию.
6. Объединить операции в единый генетический алгоритм.
7. Проверить возможность восстановления исходного текста без предварительного знания ключа.

## Используемые технологии

- Python 3
- `random` — генерация случайных значений и выполнение генетических операций.
- `string` — получение английского алфавита.
- `collections.Counter` — подсчёт частот символов.

## Принцип работы

В качестве особи используется числовой ключ шифра Цезаря. Генетический алгоритм формирует популяцию случайных ключей, оценивает их с помощью Fitness Function, отбирает лучшие варианты и создаёт новое поколение посредством скрещивания и мутации.

Оценка Fitness основана на сравнении частот букв расшифрованного текста с эталонными частотами английского языка.

## Основные параметры алгоритма

| Параметр | Значение |
|---|---:|
| Размер популяции | 100 |
| Количество поколений | 100 |
| Вероятность мутации | 0.1 |
| Диапазон начальных ключей | 1–25 |

## Результат

В ходе проверки программа успешно восстановила исходное сообщение:

**Исходный текст:**
`the quick brown fox jumps over the lazy dog`

**Зашифрованный текст:**
`ymj vznhp gwtbs ktc ozrux tajw ymj qfed itl`

**Найденный ключ:** `5`

**Результат расшифровки:**
`the quick brown fox jumps over the lazy dog`
